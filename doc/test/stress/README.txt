压力/并发测试（待补）
====================

用途:
  验证多线程竞争、长期运行、句柄/内存泄漏等非功能性问题.

计划:
  - thread: 多线程抢锁/条件变量/rwlock, 1000 轮
  - process: 反复 spawn/wait/close, 检查句柄增长
  - file/mmap: 反复打开/映射/释放, 检查资源回收
  - arena: 随机分配/释放, 检查 live 归零与峰值

说明:
  这些测试耗时且可能偶发失败, 不放进 doc/test/run.ps1 的快速回归.
  用单独脚本运行, 输出 pass/fail 与资源计数.
